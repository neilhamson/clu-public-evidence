# Conditional future roadmap

**There is no authorised restart date or budget.** These are potential workstreams, not committed milestones.

1. **Resource feasibility assessment:** evaluate local inference hardware, GPU memory, RAM, model suitability, software maintenance and expected operational expenditure.
2. **Repository and dependency review:** audit retained code, terminology, security boundaries and external dependencies without assuming existing code runs correctly.
3. **Controlled technical validation:** establish reproducible tests for selected components and clearly publish measured results, failures and limitations when authorised.
4. **Architecture decision:** assess local versus hosted inference, data protection and access permissions.
5. **Human-controlled workflows:** evaluate proposals, approvals, logging, rollback, and bounded tool access with appropriate safeguards.
6. **Evidence-driven continuation:** consider later expansion only after funding, feasibility, reliability and security evaluation.

## Potential resource needs

Computing hardware, model hosting or inference resources, storage, electricity, engineering time, evaluation and security maintenance may all have costs. **No amounts are estimated or committed in this document.**

This document is not a solicitation or investment offer.
