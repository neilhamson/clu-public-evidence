## Reorganisation and testing

The source reorganisation was committed without running tests, at the owner's explicit direction. Therefore the current reorganised codebase has **not** been comprehensively validated for runtime correctness.

Some earlier private engineering activity and validation were reported in project records. Those reports should not be treated as a fresh independent audit, public benchmark or proof that the current CLU system is operational.

## What is deliberately not claimed

- An original or independently trained CLU foundation language model.
- A currently active CLU cloud AI service.
- An independently validated general-purpose autonomous agent.
- Availability of a public CLU chatbot or paid product.
- Complete credential, historical-repository or infrastructure security certification.

For source-code inspection, a separately reviewed and expressly approved public code release would be required.
