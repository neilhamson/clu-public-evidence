# CLU project overview

CLU stands for **Codified Likeness Utility**. It is a personal Machine Intelligence / Artificial Intelligence software research project owned by Neil Hamson and developed under HamTron.

## Intended purpose

CLU's research objectives include technical assistance, software-engineering support, code and project-document analysis, project-knowledge retrieval, reasoning assistance and controlled workflows subject to human approval.

These are **objectives**, not claims that every function is complete or operational.

## Current position

All development has ceased pending adequate funding, computing resources and further technical assessment. Existing project source has been retained for possible future continuation. No restart timetable has been approved.

CLU is not a commercial AI product, a public-facing AI service or a newly trained foundation model. CLU does not currently operate an AWS AI deployment.

## Related HamTron projects

TRON is a separate cybersecurity project. Quorra, YoriBot and Anna Bot are separate projects. They should not be confused with CLU's identity or capabilities.
