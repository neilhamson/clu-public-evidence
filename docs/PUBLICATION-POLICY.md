# Public disclosure policy

This documentation package does **not** grant public access to the private CLU development repository.

Before publicly releasing code, a human reviewer should:

1. Check the entire release snapshot and relevant Git history for passwords, tokens, deploy keys, personal data and confidential configuration.
2. Verify ownership, third-party licences and permissions for all included source, datasets, images and dependencies.
3. Remove private endpoints, hostnames, operational secrets, internal paths and infrastructure details that should not be public.
4. Confirm that files match the approved scope and contain no unsupported performance or deployment claims.
5. Independently review security implications of any published runnable code or instructions.
6. Approve publication, repository settings, licence, issue/discussion settings and future contribution policy.

This repository does not include application source code until that review has been completed and publication explicitly approved.
