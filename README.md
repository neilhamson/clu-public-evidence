# CLU — Public Project Evidence

**Codified Likeness Utility (CLU)** is Neil Hamson's personal artificial intelligence research and software project under [HamTron](https://hamtron.tech).

**Development status: Ceased pending sufficient funding and resources.** There is no authorised restart date, public AI service, commercial subscription or current CLU AWS AI deployment. CLU has not trained a foundation language model.

This repository is a **curated public evidence and documentation resource**, not a mirror of the private development repository. It contains descriptions of engineering work and clearly labels the difference between source-code presence, previously reported verification and demonstrated operational functionality.
